# Shorisha Bari Dhanmondi — Website Preview

Single-page, mobile-first website preview for Shorisha Bari (Bengali comfort food, Dhanmondi, Dhaka).

- English / Bangla toggle (add `?lang=bn` to the URL to open in Bangla)
- Full-screen hero, house favourites, menu, why-us, ambience, reviews, visit info
- Call and WhatsApp buttons

Built by FutureStack Solutions. Photos are demo placeholders, to be replaced with the restaurant's own photos.
